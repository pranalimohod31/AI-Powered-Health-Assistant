# 🏥 AI-Powered Health Assistant

## Overview
AI-Powered Health Assistant is a machine learning-based web application that predicts possible diseases from user-selected symptoms and provides educational health guidance.

## Features
- Disease prediction using a trained ML model
- Prediction confidence score
- Preventive guidance
- Disease information
- AI Health Chatbot powered by Groq
- Interactive Streamlit web interface

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Groq API

## Project Structure
- `app.py` – Main Streamlit application
- `models/` – Trained ML model files
- `data/` – Dataset files
- `requirements.txt` – Dependencies
